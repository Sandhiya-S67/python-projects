# Python Projects

This repository contains a curated set of Python projects that demonstrate fundamental programming concepts, clean code practices, and interactive console-based applications.

Each script is a standalone project designed to strengthen understanding of Python basics such as control flow, functions, modularization, and practical problem-solving.

## Repository Structure

The repository currently includes the following Python projects:

- `number_guessing_game.py`  
  A console-based game where the user attempts to guess a randomly generated number within a defined range.

- `dice_rolling_game.py`  
  A simple dice rolling simulation demonstrating random number generation and user interaction.

- `rock_paper_scissor.py`  
  An implementation of the classic Rock-Paper-Scissors game using conditional statements.

- `modularizing_rock_paper_scissor.py`  
  An enhanced version of the Rock-Paper-Scissors game that applies modular programming principles.

- `applying_dry_principle_rock_paper_scissor.py`  
  A refactored Rock-Paper-Scissors implementation emphasizing the DRY (Don’t Repeat Yourself) principle.

- `qr_code_generator.py`  
  A utility script that generates QR codes from user-provided input, illustrating external library usage and file handling.

- `google.png`  
  An image asset referenced by one or more project scripts.

## Setup and Usage

To run any of the Python scripts in this repository:

1. Ensure Python is installed on your system (Python 3.7 or higher is recommended).

2. Clone the repository to your local machine:

   ```bash
   git clone https://github.com/Sandhiya-S67/python-projects.git
   ````

3. Navigate to the project directory:

   ```bash
   cd python-projects
   ```
